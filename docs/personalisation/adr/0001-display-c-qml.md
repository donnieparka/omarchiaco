# Controlli display nel popup QML

I controlli display restano nel popup QML della barra Omarchy, accessibile dall'icona dei monitor. L'utente ha scelto di accedere alle singole impostazioni tramite pulsanti nel popup esistente. La gestione nativa dei monitor e le operazioni richiamate dal pannello sono definite in [0004](0004-monitor-configuration-authority.md).
