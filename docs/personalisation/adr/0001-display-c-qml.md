# Motore display in C e interfaccia QML

Il motore delle impostazioni display sarà scritto in C, mentre i pulsanti resteranno nel popup QML della barra Omarchy. L'utente ha scelto questa separazione per accedere alle singole impostazioni direttamente nel popup esistente. Un indicatore interamente C nel vero tray avrebbe offerto voci e sottomenu al posto dei pulsanti richiesti.
